# Ddayup 网页素材采集扩展 — 隐私政策

**生效日期：** 2026-08-03
**应用名称：** Ddayup 网页素材采集扩展（Ddayup Web Asset Collector）
**开发者：** Ddayup 项目团队

## 1. 我们收集什么
本扩展**仅在你的浏览器本地**运行，用于将网页中的图片、视频、音效、3D 模型等资源扫描、下载或导入到 Ddayup 素材库。我们收集/产生的数据包括：

1. **素材元数据**：你正在浏览的网页 URL、页面标题，以及扫描到的资源链接、类型、尺寸等描述信息。这些信息保存在**浏览器本地存储（`chrome.storage.local`）**以及（如你启用了本地 Ddayup 后端）你本机的 Ddayup 数据目录中。
2. **授权信息**：用于「7 天免费试用 / 付费许可」的设备标识（随机生成的本地 UUID）、登录邮箱，以及授权状态。授权判定全部由你本地运行的 Ddayup 后端计算，不向任何第三方发送。
3. **本地账号**：若你使用登录功能，邮箱与密码以加盐哈希形式存储在你本机的 Ddayup 后端 `users.json` 中，密码不以明文保存，也不会上传到任何外部服务器。

## 2. 我们「不」做什么
- 不会将你浏览的网页内容、扫描到的素材、账号密码上传到 Ddayup 以外的任何第三方服务器。
- 不会植入广告或追踪 SDK。
- 不会出售或共享你的个人数据。

## 3. 数据如何存储与使用
- 所有数据默认保留在你**自己的设备**上。删除扩展或清除浏览器数据即可移除。
- 授权的「试用/付费」状态用于决定是否允许继续使用采集功能；该状态由你本地（或你自行部署的）Ddayup 后端判定，不依赖外部服务。

## 4. 第三方与对外连接
- 扩展仅与你在本地运行的 Ddayup 后端（`http://127.0.0.1:3000`）或你自行部署的同域名后端通信，用于账号校验与授权状态查询。
- 资源的实际下载来自**你主动浏览的源网站**（如视频/图片托管站），扩展只是把你已能访问的链接交给浏览器下载，不会中转你的流量到我们。

## 5. 你的权利
你有权随时：清除扩展的本地数据、卸载扩展、注销本地账号。由于数据均在本机，无需向我们提出删除请求。

## 6. 联系方式
如需隐私相关咨询，请通过 Ddayup 官方渠道联系开发者。

---
*本政策仅适用于「Ddayup 网页素材采集扩展」本身。Ddayup 网页端（3000 端口 Web 应用）的隐私实践以该应用各自的声明为准。*
